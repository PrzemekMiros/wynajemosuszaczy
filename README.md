# Tani Wynajem — Astro

Strona została przeniesiona do projektu Astro. Wymaga Node.js 18.20+ lub 20+.

```bash
npm install
npm run dev
```

Wydanie produkcyjne:

```bash
npm run build
npm run preview
```

Najważniejsze pliki:

- `src/pages/index.astro` — strona główna i jej dane;
- `src/layouts/BaseLayout.astro` — wspólny dokument HTML i metadane;
- `public/hero-osuszanie.png` — zdjęcie otwierające;
- `astro.config.mjs` — konfiguracja budowania do statycznego `dist/`.
